# Stayly – Booking Apartmana

Moderan, responsive MVP za pretragu i rezervaciju apartmana. Projekat je izrađen u čistom HTML, CSS i JavaScriptu i može se direktno objaviti kroz GitHub Pages.

## Pokretanje

Otvorite `index.html` u pregledaču ili aktivirajte GitHub Pages iz branch-a `main` i foldera `/ (root)`.

## Funkcionalnosti

- Pretraga po nazivu/destinaciji
- Odabir datuma dolaska i odlaska
- Odabir broja gostiju
- Lista i detalji apartmana
- Modal za rezervaciju
- Favoriti
- Responsive mobile dizajn

## Napomena

Trenutna verzija koristi lokalnu simulaciju rezervacije. Za produkcijsku verziju potrebno je povezati backend, plaćanje i bazu podataka.
